Privacy Policy

Effective date: 22 November 2026

This Privacy Policy explains how Golden Tales Uploader (the "Tool"), operated by The Golden Tales ("we", "us"), handles information. The Tool is a private, single-user application used only by the owner of the YouTube channel The Golden Tales (@TheGoldenTales.official) to upload that owner's own videos to that owner's own channel.

1. Use of YouTube API Services

The Tool uses the YouTube API Services to upload videos, set video thumbnails and confirm which channel is signed in. By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. Information we access

When the channel owner signs in with Google through OAuth 2.0, the Tool receives an access token that allows it to:

  • upload videos and thumbnails to the signed-in channel (scope youtube.upload);
  • read the signed-in channel's basic details, such as its name and ID, to confirm the correct channel is used (scope youtube.readonly).

The Tool does not access, collect or process any information about any other YouTube user, viewer or channel.

3. How information is used

The access granted is used only to upload the channel owner's own videos with the titles, descriptions, tags and thumbnails the owner has written, and to confirm the destination channel. No information is used for advertising, profiling, analytics or any other purpose.

4. Storage

The only information the Tool stores is the channel owner's OAuth token. It is stored locally, in a private file on the owner's own computer. It is not stored on any server, and no data obtained from the YouTube API Services is stored. The video files and their metadata originate on the owner's computer and are not collected from YouTube.

5. Sharing

We do not sell, share, rent or disclose any information to third parties. Videos are sent only to YouTube, as directed by the channel owner.

6. Cookies and tracking

The Tool is a local application and does not use cookies, tracking pixels or device identifiers. This website does not use cookies or analytics.

7. Revoking access and deleting data

Access can be revoked at any time on the Google security settings page at https://security.google.com/settings/security/permissions. Deleting the local token file also removes all stored data immediately. Any stored token is deleted within 7 days of access being revoked or of a deletion request, and no other API data is retained.

8. Children

The Tool is not directed to children and is used only by the adult channel owner.

9. Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
